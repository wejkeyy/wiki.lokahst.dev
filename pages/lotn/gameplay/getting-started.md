## First Join

Character creation is enabled by default. Until it is finished, progression stays locked and LotN commands reopen the setup menu.

1. Keep your Minecraft username or enter a separate character name.
2. Choose one of the five races.
3. Open `/lotn` to access the rest of the plugin.

## Main Command

`/lotn` always opens the main GUI. Any extra command arguments are ignored.

The menu includes:

- Character
- Skills
- Quest Journal
- Enchantments
- Alchemy
- Shouts
- Fast Travel
- Codex
- Fishdex
- Fish Exchange

## Starting Character Values

| Stat | Starting value |
|---|---|
| Character level | 1 |
| Maximum Health | 100 |
| Maximum Stamina | 100 |
| Maximum Magicka | 100 |
| Carry capacity | 200 |
