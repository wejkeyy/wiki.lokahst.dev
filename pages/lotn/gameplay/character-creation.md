Character creation is enabled by default. Players cannot use the normal LotN systems until setup is finished.

## Character Name

A character can use the player's Minecraft username or a separate name entered in chat.

| Setting | Default |
|---|---|
| Minimum length | 3 characters |
| Maximum length | 20 characters |
| Unique names | Yes |
| Cancel word | `cancel` |
| Allowed pattern | `[A-Za-z][A-Za-z0-9 _'\-]*` |

The name must start with a letter. After that, it may contain numbers, spaces, apostrophes, underscores, and hyphens. The default name blacklist is empty.

## Race Selection

After choosing a name, the player selects one of five races. This choice cannot be changed normally; an administrator must change it through `/lotnea`.

## Setup Lock

Until setup is finished, `/lotn` opens character creation instead of the main menu.
