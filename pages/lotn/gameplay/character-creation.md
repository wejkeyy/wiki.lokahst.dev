Character creation is enabled by default and blocks normal LotN gameplay until it is completed.

## Character Name

The character name is separate from the Minecraft username. Players may use their Minecraft name or enter another name in chat.

| Setting | Default |
|---|---|
| Minimum length | 3 characters |
| Maximum length | 20 characters |
| Unique names | Yes |
| Cancel word | `cancel` |
| Allowed pattern | `[A-Za-z][A-Za-z0-9 _'\-]*` |

The default pattern requires the first character to be a letter. Numbers, spaces, apostrophes, underscores, and hyphens may be used afterward.

## Race Selection

After naming the character, the player chooses one of five races. The choice is permanent through normal gameplay.

See [Races](races.md) for every racial bonus and penalty.

## Setup Lock

Before setup is complete, LotN prevents the player from beginning normal progression and reopens the setup interface when a LotN command is used.
