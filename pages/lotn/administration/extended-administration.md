---
title: Extended Administration
description: Tools available in /lotnea
updated: August 1, 2026
---


`/lotnea` opens the admin menu. It requires `lotn.admin` and cannot be used from the console.

## Target Player

Choose an online player first. The rest of the menu then edits that player's data.

## Character

- Change race
- Start a chat-based character rename
- Reset the character name to the Minecraft username

## Skills

- Inspect every skill
- Add 1 level, add 10 levels, or set one skill to its maximum
- Max every skill, reset one skill, or reset every skill

## Vitals and Injuries

- Heal Health, Stamina, and Magicka
- Add vitality choices in amounts of 1, 10, or 1000
- Apply Health, Stamina, or Magicka upgrades in 1 or 10 choice batches
- Break or heal the target's leg

## Alchemy

- Unlock all recipes
- Give the highest available quality of a selected potion
- Unlock individual recipes

## Fishing

- Discover all fish
- Reset the Fishdex

## Shouts

- Unlock all shouts
- Lock all shouts
- Reset all cooldowns
- Add or remove unlocked words for individual shouts

## Enchantments

- Discover all enchantments
- Apply a compatible LotN enchantment to the held item
- Remove all LotN enchantments from the held item

## Server Settings

- Toggle vanilla enchanting tables
- Toggle vanilla enchanted books
- Toggle XP action bars
- Reload LotN configuration and services

The GUI checks only `lotn.admin`. Several smaller admin permissions exist in `plugin.yml`, but this build does not use them inside the menu.
