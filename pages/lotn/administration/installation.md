## Server Requirement

LotN is built against Paper API `1.21.11` and loads at `POSTWORLD`.

## Soft Dependencies

| Plugin | Required | Used for |
|---|---|---|
| Vault | No | Balances, money rewards, and Fish Exchange sales |
| PlaceholderAPI | No | `%lotn_*%` placeholders |

## First Check

After the first startup, join as an administrator and finish character creation. Open both `/lotn` and `/lotnea`, then check the console for invalid materials, recipes, sounds, YAML errors, or migration warnings.
